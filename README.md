# 🏫 CampusFix AI

> **AI-Powered Campus Maintenance Management System**

A modern, intelligent platform for managing campus maintenance issues with multilingual support, real-time tracking, and AI-driven analytics.

---

## ✨ Features

### 🎯 Core Functionality
- **Smart Issue Reporting** - Students can report maintenance issues with photos and voice input
- **AI-Powered Triage** - Gemini AI automatically categorizes and prioritizes tickets
- **Interactive Map** - Visual location picker with address search powered by Leaflet
- **Real-time Dashboard** - Live tracking of all maintenance requests
- **Admin Heatmap** - Geographic visualization of issue hotspots

### 🌍 Multilingual Support
Support for **9 Indian languages** plus English:
- Hindi (हिंदी)
- Marathi (मराठी)
- Gujarati (ગુજરાતી)
- Tamil (தமிழ்)
- Telugu (తెలుగు)
- Kannada (ಕನ್ನಡ)
- Bengali (বাংলা)
- Malayalam (മലയാളം)
- English

Students can report issues in their native language, and AI provides responses in the same language!

### 🤖 AI Features
- **Automatic Categorization** - AI classifies issues into: Electrical, Water, Cleanliness, Infrastructure, Safety, Technology, Other
- **Priority Scoring** - Urgency rated 1-10 based on description and image analysis
- **AI Fix Guides** - Step-by-step repair instructions generated by Gemini AI
- **Language Detection** - Automatic translation and native language responses

### 📊 Analytics & Transparency
- **Public Transparency Page** - Live statistics accessible to all students
- **Google Sheets Integration** - One-click sync of all ticket data for analysis
- **Resolution Metrics** - Track total tickets, resolved issues, and resolution rates
- **Hotspot Identification** - Identify buildings/areas with most reports

## 📦 Installation

### Prerequisites
- Node.js 18+ 
- npm or yarn
- Firebase account
- Google Gemini API key

### Setup

1. **Clone the repository**
```bash
git clone https://github.com/omar-h-Hashmi-rgb/campusfix.git
cd campusfix
```

2. **Install dependencies**
```bash
npm install
```

3. **Configure environment variables**

Create a `.env.local` file in the root directory:

```env
# Firebase Configuration
NEXT_PUBLIC_FIREBASE_API_KEY=your_firebase_api_key
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
NEXT_PUBLIC_FIREBASE_DATABASE_URL=https://your_project.firebaseio.com
NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_project_id
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your_project.appspot.com
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
NEXT_PUBLIC_FIREBASE_APP_ID=your_app_id

# Google Gemini AI
NEXT_PUBLIC_GEMINI_API_KEY=your_gemini_api_key
```

4. **Set up Firebase**
   - Create a new Firebase project at [Firebase Console](https://console.firebase.google.com)
   - Enable **Realtime Database**
   - Enable **Email/Password Authentication**
   - Copy your config values to `.env.local`

5. **Get Gemini API Key**
   - Visit [Google AI Studio](https://makersuite.google.com/app/apikey)
   - Create a new API key
   - Add it to `.env.local`

6. **Run the development server**
```bash
npm run dev
```

7. **Open your browser**
```
http://localhost:3000
```

## 🎨 Features Walkthrough

### For Students

#### 1. Report an Issue
- Navigate to `/report`
- Select category (Electrical, Water, etc.)
- Choose language preference
- Add description (text or voice)
- Upload photo (optional)
- Pick location on map
- Submit!

#### 2. Track Your Tickets
- View all your submitted tickets at `/dashboard`
- See real-time status updates
- Check AI-generated summaries
- View resolution progress

#### 3. Public Transparency
- Visit `/transparency` to see:
  - Total tickets reported
  - Issues resolved
  - Resolution rate
  - Recent fixes
  - Hotspot areas

### For Admins

#### 1. Admin Dashboard
- Access at `/admin` (requires admin privileges)
- View all tickets with filters
- See geographic heatmap
- Update ticket status
- Generate AI fix guides

#### 2. Analytics Sync
- Click "Sync to Analytics" button
- Exports all ticket data to Google Sheets
- Opens success confirmation in new tab
- Data includes: ID, title, category, priority, status, location, timestamp

#### 3. AI Fix Guide
- Click "AI Fix" on any ticket
- Gemini AI generates:
  - Step-by-step repair instructions
  - Estimated completion time
  - Required tools/materials

## 🔧 Configuration

### Firebase Database Rules
```json
{
  "rules": {
    "tickets": {
      ".read": "auth != null",
      ".write": "auth != null"
    }
  }
}
```

### Admin Setup
To make a user an admin:
1. User must sign up first
2. Go to Firebase Console → Realtime Database
3. Navigate to `/users/{userId}`
4. Add field: `"isAdmin": true`
